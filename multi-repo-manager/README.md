# Multi Repo Manager

Manage multiple Home Assistant add-on repository URLs from a clean, dark web UI.

## Features
- Add, remove, enable/disable repository entries
- One-click "Open in Home Assistant" deeplinks
- Copy URL to clipboard
- REST API for automation
- Persistent storage in `/addon_configs/`

## Install

[![Add repository](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fgemichelst%2Fha-addons)

Install **Multi Repo Manager** from the App Store, start it, open via the sidebar panel.
