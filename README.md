# gemichelst Home Assistant Apps

Custom Home Assistant App (Add-on) repository by gemichelst.

## Apps

| App | Description |
|-----|-------------|
| [Multi Repo Manager](./multi-repo-manager) | Manage multiple HA add-on repository URLs from a clean web UI |

## Installation

[![Add repository](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fgemichelst%2Fha-addons)

Or manually:
1. Open **Settings → Apps → App Store**
2. Click the ⋮ menu → **Repositories**
3. Add: `https://github.com/gemichelst/ha-addons`
